# Insight Advora LLP — Website + CMS

Corporate website and admin panel for **Insight Advora LLP** (www.insightadvora.com) — *Partnering for Smarter Decisions*.

- **Specification / design handoff:** [docs/HANDOFF.md](docs/HANDOFF.md)
- **Setup, database migration and deployment:** [DEVELOPMENT.md](DEVELOPMENT.md)

Stack: Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Framer Motion · Prisma · PostgreSQL (Supabase).

```bash
npm install
cp .env.example .env
npm run dev
```
